# Sleight School

13 card tricks &amp; sleights, ordered so each one teaches you the next — from the Key Card Principle up to Triumph.

**View the guide:** open `index.html` in a browser (or enable GitHub Pages on this repo).

## Contents

**Foundations** — Key Card Principle · Overhand Shuffle Control · Hindu Shuffle &amp; Force · Double Lift · False Cut

**The Moves** — The Glide · Riffle Force · Elmsley Count · Snap Change

**Routines** — 21-Card Trick · Two-Card Monte · Ambitious Card · Triumph

Each trick has written step-by-step instructions, an embedded video tutorial, and a link to the best illustrated guide available.
